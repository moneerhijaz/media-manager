# Security

Do not post credentials, library databases, web tokens, media, or unredacted logs in public issues. Report reproducible problems with synthetic media and scrubbed configuration. No dedicated private reporting channel is declared here; arrange a private channel with the maintainer before disclosing sensitive details.

The dashboard can initiate file-changing work. Bind local evaluation to `127.0.0.1`, keep initial setup private, and follow [safety guidance](docs/SAFETY.md). Review externally supplied subtitles and model dependencies as inputs from other systems.
